# Heart Disease Prediction System

A machine learning project that predicts whether heart disease is likely from **4 clinical attributes**, using a Support Vector Classifier (SVC). It follows the same step-by-step structure as the Titanic Passenger Survival Prediction notebook (Import Libraries -> Load Data -> Pre-process -> Train -> Test -> Application -> Feedback -> Deploy).

> **Educational project only - not a medical diagnosis tool.**

## Try It Online

**[Heart Disease Predictor - Live App](PASTE-YOUR-STREAMLIT-LINK-HERE)**

## Dataset

[UCI Heart Disease dataset](https://archive.ics.uci.edu/dataset/45/heart+disease) - Cleveland Clinic database (`processed.cleveland.data`, 303 patients). The 5-level output `num` (0-4) is converted to binary: 0 = no heart disease, 1 = heart disease present.

## Inputs and Output

| Input | Meaning | Values |
|---|---|---|
| **Sex** | Sex of the patient | 1 = Male, 0 = Female |
| **CP** | Chest pain type | 1 = Typical angina, 2 = Atypical angina, 3 = Non-anginal pain, 4 = Asymptomatic |
| **Exang** | Exercise-induced angina | 1 = Yes, 0 = No |
| **Oldpeak** | ST depression induced by exercise | Decimal, 0.0 - 6.2 |

| Output | Values |
|---|---|
| **HeartDisease** | 1 = Yes, 0 = No |

All inputs are already numeric, so **no label encoding** is used.

## Results (held-out test set, 61 patients)

| Metric | Value |
|---|---|
| Accuracy | 0.72 |
| Precision (heart disease) | 0.80 |
| Recall (heart disease) | 0.62 |

## Run Locally

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (macOS/Linux: source venv/bin/activate)
pip install -r requirements.txt
streamlit run app.py
```

Opens at `http://localhost:8501`.

## Deploy on Streamlit Community Cloud (free)

1. Go to https://share.streamlit.io and sign in with GitHub.
2. Click **Create app** -> **Deploy a public app from GitHub**.
3. Repository: `<your-username>/<this-repo>`, Branch: `main`, Main file path: `app.py`.
